# xldiff

2つの Excel ファイル(.xlsx / .xlsm)の差分を、git diff のように1行1変更で表示する CLI ツールです。

Claude Code などの LLM に Excel を読ませると、ファイル全体を展開するためトークンを大量に消費します。xldiff は変更箇所だけを短いテキストで出力するので、「どこが変わったか」を少ないトークンで渡せます。

```
$ xldiff examples/base.xlsx examples/06_mixed.xlsx
--- examples/base.xlsx
+++ examples/06_mixed.xlsx
@@ シート1 @@
~ A2 style: fill.fgColor: none → 00FFFF00, fill.pattern: none → solid
~ C3 link: "https://example.com/rec/02" → "https://example.com/rec/02-fixed"
+ row 5: A5: "第三回補講" | B5: "日付: 2025年4月23日 10:00 AM" | C5: "https://example.com/rec/03-extra"
~ B7 (was B6) comment: (none) → "音声が途中で切れている"
~ B10 (was B9): "日付: 2025年5月26日 10:00 AM" → "日付: 2025年5月27日 10:00 AM"
+ merge A1:C1
@@ メモ (added sheet: A1:B2 (4 cells)) @@
+ row 1: A1: "未視聴" | B1: 3
+ row 2: A2: "合計" | B2: =COUNTA(シート1!A2:A15)
```

この例のファイルは `scripts/make_variants.py` で生成できる架空のサンプルです([開発](#開発)を参照)。

## インストール

Python 3.12 以上と [uv](https://docs.astral.sh/uv/) が必要です。

```sh
git clone <このリポジトリの URL>
cd <クローンしたフォルダ>
uv tool install -e .     # xldiff コマンドがどこからでも使えるようになる
```

`-e`(editable)でインストールしているため、ソースを変更すると再インストールなしで反映されます。アンインストールするときは `uv tool uninstall xldiff` を実行します。

## 使い方

```
xldiff OLD.xlsx NEW.xlsx [オプション]
```

| オプション | 説明 |
|---|---|
| `-f json` | JSON で出力(既定は `compact`) |
| `--stat` | シートごとの件数サマリだけを表示 |
| `--no-style` | 書式(フォント・塗り・罫線・表示形式・行高・列幅・条件付き書式)の差分を無視 |
| `-s NAME` | 対象シートを絞り込む(複数指定可) |
| `--color auto\|always\|never` | カラー表示。既定の `auto` は端末に出すときだけ色を付け、パイプやファイルへの出力では付けない。環境変数 `NO_COLOR` があれば無効 |
| `--max-len N` | 長い値を N 文字で切り詰める |
| `--indent N` | JSON を整形する(既定は1行に詰める) |
| `--exit-code` | 差分があれば終了コード 1 を返す |

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 正常終了(差分の有無を問わない) |
| 1 | 差分あり(`--exit-code` 指定時のみ) |
| 2 | エラー(ファイルが存在しない、.xls 形式など) |

`git diff` と同じく、差分がなければ何も出力しません。

## 出力の読み方(compact 形式)

| 行 | 意味 | 座標 |
|---|---|---|
| `@@ シート名 @@` | シートの区切り。`(renamed from 旧名)` `(added sheet)` `(removed sheet)` が付くことがある | |
| `~ B3: 旧 → 新` | セルの値・数式の変更。`(empty)` は空セル | 新ファイル。位置が動いたセルには `(was B2)` が付く |
| `~ B3 style: font.bold: false → true, ...` | 書式の変更(変わった属性だけを表示) | 同上 |
| `~ B3 link: ...` / `~ B3 comment: ...` | ハイパーリンク・コメントの変更 | 同上 |
| `+ row 5: A5: ... \| B5: ...` | 挿入された行 | 新ファイル |
| `- row 9: A9: ... \| B9: ...` | 削除された行 | 旧ファイル |
| `+ col D: ...` / `- col D: ...` | 挿入・削除された列 | 同上 |
| `~ row 5 height: ...` / `~ col C width: ...` | 行の高さ・列幅・非表示の変更 | 新ファイル |
| `+ merge A1:C1` / `- merge ...` | セル結合の追加・解除 | |
| `~ sheet freeze: ...` | ウィンドウ枠の固定・オートフィルタ・シートの表示状態・タブ色の変更 | |
| `+ condfmt ...` / `+ validation ...` | 条件付き書式・入力規則の追加・削除 | |
| `~ name X: ...` | 名前定義の変更 | |

値の表記は次のとおりです。

- 文字列は `"..."` で囲む。改行は `\n` と表記する。
- 数値・真偽値(`TRUE` / `FALSE`)・日付(`2025-04-07`)は囲まない。
- 数式は `=SUM(A1:A3)`、配列数式は `{=...}` と表記する。

## 差分検出の仕組み

### 行・列の対応付け

git diff と同様に、内容で行を対応付けます。表の途中に1行挿入しても、それより下の行がすべて「変更」と表示されることはありません。手順は次のとおりです。

1. 内容が完全に一致する行どうしを最長共通部分列で対応付ける。
2. 一致しなかった区間は、セル単位の類似度で「変更された行」と「挿入・削除された行」に分ける。
3. 列も同じ考え方で対応付ける。列の比較には値の集合を使うので、行の挿入があっても列の対応は崩れない。

### 数式の参照ずれ

Excel で行を挿入すると、それより下を参照している数式は自動で書き換わります(`=A5` → `=A6`、`=SUM(C1:C8)` → `=SUM(C1:C9)`)。xldiff は旧ファイルの数式の参照を、行・列の対応表で新しい座標に写像してから比較します。そのため、この書き換えは差分として表示されません。

### その他の正規化

- 日付は内部でシリアル値として比較する。表示形式を「日付」から「標準」に変えた場合は、書式の変更だけが表示される。
- 書式はスタイル ID ではなく属性値で比較する。そのため、保存し直しただけで生じる内部 ID の変化は差分にならない。
- 値も書式も持たない空セルは無視する。

## JSON 出力

`-f json` を指定すると、プログラムで処理しやすい構造で出力します。値は型付きの生の値(文字列・数値・真偽値、日付は ISO 形式の文字列)になります。

```json
{"old_path": "a.xlsx", "new_path": "b.xlsx",
 "sheets": [{"name": "S", "status": "modified",
   "rows": [
     {"op": "modify", "old_row": 2, "new_row": 2,
      "changes": [{"addr": "B2", "value": {"old": "name1", "new": "改名"}}]},
     {"op": "insert", "new_row": 4,
      "cells": [{"addr": "A4", "value": 50}, {"addr": "B4", "value": "x"}]}]}],
 "identical": false}
```

## Claude Code から使う

他のプロジェクトの `CLAUDE.md` に、次のように書いておくと便利です。

```markdown
## Excel ファイルの扱い
- Excel ファイルの変更内容を確認するときは、ファイル全体を読まずに
  `xldiff 変更前.xlsx 変更後.xlsx` で差分だけを取得すること。
- 変更の規模を先に知りたいときは `xldiff --stat` を使う。
```

## 制限事項

- **未対応の形式:** .xls(Excel 97-2003 形式)は読めないので、.xlsx で保存し直してください。パスワード付きのファイルにも対応していません。
- **比較しない要素:**
  - 図形・グラフ・画像
  - セル内の部分的な書式(リッチテキスト)
  - 数式の計算結果のキャッシュ値(数式は数式テキストで比較します)
- **コメント:** Excel 365 の「スレッド形式のコメント」は openpyxl で読めません。互換用の「メモ」として保存されたテキスト(`[Threaded comment]...` という定型文を含む)で比較します。
- **条件付き書式・入力規則:** 適用範囲を文字列のまま比較します。行の挿入で範囲がずれると、「削除+追加」として表示されます。
- **対応付けの判定:** 行の内容をその場ですべて書き換えた場合は、行の削除+挿入ではなく、セルの変更として表示されることがあります。
- **速度:** 読み込みは openpyxl に依存しており、20万セル程度のファイルでは1ファイルあたり約4秒かかります。

## 開発

```sh
uv sync                                # 開発環境(pytest を含む)
uv run pytest                          # テスト(テスト用の Excel は実行時に一時フォルダへ生成する)
uv run python scripts/make_variants.py # 架空のサンプル base.xlsx と編集版 7 種類を examples/ に生成
uv run xldiff examples/base.xlsx examples/06_mixed.xlsx
```

`examples/` に生成されるファイルは次のとおりです。いずれも `base.xlsx` と比較して使います。

| ファイル | base.xlsx からの編集内容 |
|---|---|
| `01_resave.xlsx` | 何も変えずに保存し直しただけ(差分なしになることの確認用) |
| `02_cell_edit.xlsx` | B3 の日付を変更 |
| `03_row_insert.xlsx` | 5 行目に「第三回補講」の行を挿入 |
| `04_row_delete.xlsx` | 第八回(9 行目)を削除 |
| `05_col_insert.xlsx` | B 列に「担当」列を挿入 |
| `06_mixed.xlsx` | 行挿入・セル変更・書式・リンク・コメント・結合・シート追加の複合 |
| `07_rename_format.xlsx` | シート名・列幅・表示形式を変更 |

構成:

| ファイル | 役割 |
|---|---|
| `src/xldiff/loader.py` | openpyxl で読み込み、値・書式・リンク・コメントを比較用に正規化する |
| `src/xldiff/align.py` | 行・列の対応付け(LCS と類似度による動的計画法) |
| `src/xldiff/formula.py` | 数式中のセル参照の書き換え |
| `src/xldiff/differ.py` | シートの対応付けとセルの比較。差分モデルを組み立てる |
| `src/xldiff/model.py` | 差分モデル(各出力形式の共通の入力) |
| `src/xldiff/render.py` | compact / stat / JSON 形式の出力 |
| `src/xldiff/cli.py` | コマンドライン引数の処理 |
